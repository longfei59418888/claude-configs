# Playwright MCP 使用规则

当任务需要访问网页或与网页进行交互时（包括但不限于：打开链接、查看页面内容、登录网站、点击按钮、填写表单、截图、提取页面信息、验证页面 UI 等），必须优先使用 Playwright MCP，不得仅依赖 HTTP 请求或根据已有知识进行推断。

## 执行流程

1. 如 Playwright MCP 未启动，则先启动 Playwright MCP。
2. 使用 Playwright 打开目标链接（URL）。
3. 完成任务所需的全部页面操作。
4. 获取并整理所需的信息。
5. 在输出最终结果之前，必须执行资源清理。

## 资源清理（强制要求）

无论任务执行成功、失败、发生异常或被中断，都必须执行以下清理操作：

- 关闭所有已打开的 Page（页面）。
- 关闭所有 BrowserContext（浏览器上下文）。
- 关闭 Browser（浏览器实例）。
- 确保 Playwright 启动的 Chromium/Chrome 浏览器进程已全部退出。
- 确保 Playwright MCP 产生的相关进程已释放，不遗留后台进程。
- 释放 Playwright 占用的调试端口及其他系统资源。
- 不得遗留任何孤立（Orphan）的浏览器进程。


## 完成标准

只有在确认所有 Playwright 相关资源均已释放后，任务才视为完成，可以输出最终结果。


## 特别说明
每次使用 Playwright MCP 完成网页访问后，应立即执行浏览器关闭和资源清理，不需要等待用户主动要求。
禁止为了复用浏览器而保留 Chromium/Chrome 进程。
除非用户明确要求保持浏览器打开，否则任务结束时必须关闭浏览器，并确保不存在任何 Playwright 或 Chromium/Chrome 残留进程。
